# Проверка демонстрации одного хода

Дата: 12 октября 2026.

- Unity 6000.6.4f1: успешны Builds/OneTurn/DustAndPowder-OneTurn.exe и Builds/Web. В журналах обеих сборок есть BANG_BUILD_SUCCESS.
- Чистые правила: 115 проверок нового хода; 51 429 проверок сохранённого старого ядра (400 матчей). Все проходят.
- В браузере проверены загрузка пользовательских POLYGON-моделей, запуск фазы действий и пауза. После исправления link.xml новых ошибок отсутствующих Collider в проверенных запусках не наблюдалось; консоль хранит ошибки предыдущей сборки.
- Windows: записан полный показ через Direct3D 11, 243 кадра при 10 кадрах/с. Проверены кадры уклонения, попадания, промаха и выбывания. Из реальных кадров игры собран one-turn-action.gif.
- Камера самодействия направлена с улицы на лицо персонажа. Выстрел начинается общим кадром стрелка и цели, затем камера показывает реакцию цели. Салун отодвинут, чтобы не закрывать персонажей.

Ограничения: один ход, фиксированные демонстрационные планы ботов и временный порядок исполнения. Лечение использует жест перезарядки. Сила, ловкость, интеллект и окончательная инициатива ещё не реализованы. Онлайн в новой демосцене ещё не подключён.

Для записи кадров: запустить Windows-сборку с -force-d3d11 --capture-one-turn <папка>. Окно должно быть видимым: скрытый запуск на проверенной системе даёт чёрные кадры либо ошибку захвата. Обычный запуск через Play.cmd записи не делает.

Исправление хвата: положение рукояти откалибровано относительно кисти; поворот сокета вычисляется в позе Aim, затем сохраняется относительно RightHand. Дульная точка закреплена на модели револьвера. Повторно записаны все 243 кадра хода; визуально проверены прицеливание, выстрел, уклонение и реакция на попадание. В журнале Windows-запуска нет ошибок аниматора или исключений.
